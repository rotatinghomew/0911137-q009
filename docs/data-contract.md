# 资料口径

readings 中 mode=counter 是累计读数，mode=interval 是该段用量；start/end 为天序号半开区间。revision 只在相同 reading_id 内比较，known_day 是资料可用时间。meters 记录换表日期与计数起点，不能跨表底作差。conditions 的 production 为工况，temperature 为当日气温；annotations 是分析师已经确认的边界，不能覆盖为自动候选。当前仅显示读数与备注。

## 现有资料

- `readings`：201 条本地记录。
- `conditions`：200 条本地记录。
- `meters`：4 条本地记录。
- `annotations`：1 条本地记录。

所有日期、月份、周或小时均用各表中的整数业务时标，页面的分析时点使用同一单位。资料中的 known 字段表示该行信息何时对分析可见，不是数据载入时间。字段名按原始业务接口保留。

这些记录是项目随附的虚构业务数据，不包含真实员工、客户、交易或设备。`fixtures/data.json` 的表结构可通过资料查阅页面检查；服务不从外网补数。

## 分析版本

当前分析从同一份文件一次读取所有表，并把原始字节的 SHA-256 与筛选条件一起返回。保存分析时重新基于指定条件计算，保存的是结果值及该次资料指纹，而不是指向未来可变数据的引用。已有版本只读；同名保存产生另一条版本。历史结果保留原有字段语义，不因最新源文件被替换而重算。
